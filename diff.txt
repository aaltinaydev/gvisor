+* **Credentials GC vs Dentry Lifetime:** gVisor uses Go's garbage collector, which is non-deterministic. Storing `vfs.Dentry` references inside `auth.Credentials` without deterministic cleanup will leak memory or cause panics.

+  * `pkg/sentry/vfs/anonfs.go` (to implement `WalkAncestors` as no-op)

+## 2. Security & Concurrency Hazards
+* **Dentry Reference Count and Lifecycle:**
+  * In Go, garbage collection is non-deterministic. However, `vfs.Dentry` references require explicit reference counting (`IncRef`/`DecRef`). Storing references to dentries in the Landlock ruleset/domain without deterministic cleanup will leak memory or cause panics.
+  * *Resolution:* The `Domain` struct in `pkg/sentry/landlock` must be reference counted. When a task restricts itself, register a `TaskDestroyAction` on the `Task` pointing to the `Domain`. When the task exits (in `task_exit.go`), it will execute the action, decrementing the domain's reference count. When the count reaches 0, release all dentry references by calling `DecRef` on each.
+  * *Fork/Clone:* During clone/fork, the child inherits the credentials (which copy the domain pointer) and must increment the domain's reference count and register its own `TaskDestroyAction`.
+* **Lock-Free Access Check (Read path):**
+  * Path checking occurs on every file open, mkdir, unlink, etc. Acquiring a global lock or ruleset lock on the check path would kill performance.
+  * *Resolution:* The `Domain` struct must be completely immutable once committed to credentials. If a task restricts itself again, merge the rulesets and create a *new* `Domain` struct, replacing it in the credentials. Since it is immutable, `checkLandlockPath` can walk the tree and check rules without holding any locks.
+* **Ancestry Walk Race Condition:**
+  * Walking up the parent directory chain to check rules can race with concurrent rename operations (moving a directory).
+  * *Resolution:* Define an optional interface in `pkg/sentry/vfs`:
+    ```go
+    type AncestorsWalker interface {
+        WalkAncestors(ctx context.Context, d *Dentry, cb func(*Dentry) bool) error
+    }
+    ```
+    Implement it in `genericfstree` (used by `tmpfs`, `gofer`, etc.) and `kernfs`. The implementation must acquire the filesystem's internal ancestry lock (e.g. `fs.ancestryMu.RLock()`) for the *duration of the walk* to prevent concurrent parent writes.
+* **Privilege Escalation during sandbox enforcement:**
+  * Landlock enforcement via `landlock_restrict_self` must require that the thread has `no_new_privs` set or has `CAP_SYS_ADMIN` in its user namespace.
+* **Double Path Resolution overhead:**
+  * For metadata operations (mkdir, unlink, symlink), generic VFS layer must resolve the parent directory first via `getParentDirAndName` to check Landlock permissions before delegating to the filesystem.
+  * *Resolution:* Skip the VFS resolution entirely if the task does not have a Landlock domain active (checks `creds.Security == nil`). This ensures zero performance overhead for non-sandboxed tasks.
+* **Cross-Directory Rename/Link (REFER Restriction):**
+  * Landlock ABI v1 does not support `LANDLOCK_ACCESS_FS_REFER` (implicitly denied). Cross-directory rename and link must be denied.
+  * *Resolution:* Resolve the parent directory of both source and destination. If they are not the same (`oldParentVD != newParentVD`), return `EXDEV`.
+
+## 3. Helper & Dependency Mapping
+* `getMountpointAt` crossing mount points: We use `vfs.getMountpointAt` to cross mount boundaries when climbing up the path.
+* `RootFromContext` for VFS root: We use `RootFromContext(ctx)` to retrieve the current task's VFS root as the boundary for the path walk.
+* `neverConnected` check: Skip Landlock checks for dentries on mounts where `mnt.neverConnected()` is true (counterpart of `SB_NOUSER` in Linux).
+
+## 4. High-Level Plan
+1. Define Landlock ABI structures and constants in `pkg/abi/linux/landlock.go`.
+2. Add `Security any` field to `auth.Credentials` struct and update `Fork` to copy it.
+3. Define `AncestorsWalker` interface in `pkg/sentry/vfs/filesystem.go` and implement it in `genericfstree.go` and `kernfs.go`.

+5. Register Landlock syscalls in `pkg/sentry/syscalls/linux/linux64.go` and implement handlers in `pkg/sentry/syscalls/linux/sys_landlock.go`.
+6. Integrate Landlock checks into VFS methods in `pkg/sentry/vfs/vfs.go`:

+## 1. ABI Definitions (`pkg/abi/linux/landlock.go`)

+* Rule types: `LANDLOCK_RULE_PATH_BENEATH`
+* Filesystem access masks: `LANDLOCK_ACCESS_FS_*`
+* Landlock v1 filesystem mask:
+  ```go
+  LANDLOCK_MASK_ACCESS_FS = LANDLOCK_ACCESS_FS_EXECUTE |
+      LANDLOCK_ACCESS_FS_WRITE_FILE |
+      LANDLOCK_ACCESS_FS_READ_FILE |
+      LANDLOCK_ACCESS_FS_READ_DIR |
+      LANDLOCK_ACCESS_FS_REMOVE_DIR |
+      LANDLOCK_ACCESS_FS_REMOVE_FILE |
+      LANDLOCK_ACCESS_FS_MAKE_CHAR |
+      LANDLOCK_ACCESS_FS_MAKE_DIR |
+      LANDLOCK_ACCESS_FS_MAKE_REG |
+      LANDLOCK_ACCESS_FS_MAKE_SOCK |
+      LANDLOCK_ACCESS_FS_MAKE_FIFO |
+      LANDLOCK_ACCESS_FS_MAKE_BLOCK |
+      LANDLOCK_ACCESS_FS_MAKE_SYM
+  ```
+
+## 2. Credentials Field (`pkg/sentry/kernel/auth/credentials.go`)
+* Add `Security any` field to `auth.Credentials`.
+* Since `auth.Credentials` is shared between tasks, the object stored in `Security` must be thread-safe (in our case, immutable `Domain` pointer).
+* Update `Fork` to copy the `Security` field.
+* Define `clone` / `copy` behavior on credentials or tasks. When creating a task (`newTask` in `task_start.go`), if `Credentials.Security` is not nil:
+  * Check if it implements an interface to increment reference count.
+  * Register a `TaskDestroyAction` to decrement the reference count of the domain when the task exits.
+
+## 3. VFS Ancestors Walking Interface (`pkg/sentry/vfs/filesystem.go`)
+* Define the `AncestorsWalker` interface:
+  ```go
+  type AncestorsWalker interface {
+      WalkAncestors(ctx context.Context, d *Dentry, cb func(*Dentry) bool) error
+  }
+  ```
+* Implement it in `pkg/sentry/vfs/genericfstree/genericfstree.go`:
+  * Use the filesystem's `ancestryMu` (acquire RLock) to prevent race conditions during walks.
+* Implement it in `pkg/sentry/fsimpl/kernfs/kernfs.go`:
+  * Accessing parent in kernfs: walk up by acquiring appropriate locks.
+* Implement it in `pkg/sentry/vfs/anonfs.go` as no-op.
+
+## 4. Landlock Package (`pkg/sentry/landlock`)
+Create a new package containing:
+* **Ruleset**:
+  * Represents a mutable ruleset during construction.
+  * Fields: `mu sync.Mutex`, `handledAccessFS uint64`, `rules map[*vfs.Dentry]uint64` (maps a directory/file dentry to allowed access mask).
+  * Has a lock to protect rules.
+* **RulesetFileDescription**:
+  * Implements `vfs.FileDescriptionImpl`.
+  * Wraps a `*Ruleset` pointer.
+  * Created via `landlock_create_ruleset`.
+* **Domain**:
+  * Represents an immutable, stacked set of rulesets.
+  * Fields: `refs refs.RefCounter`, `layers []*Ruleset` (which are now treated as immutable layers).
+  * Implements `kernel.TaskDestroyAction`.
+  * Reference counted: `DecRef` decrements the ref count. When it hits 0, it calls `DecRef` on all `vfs.Dentry` objects stored in the maps of its layers.
+* **Access Checking Logic**:
+  * `checkLandlockPath(ctx context.Context, domain *Domain, path vfs.Path, accessRequest uint64) error`:
+    * Initializes `layer_masks` for `accessRequest`.
+    * If `layer_masks` is empty, return nil.
+    * Walks up the ancestry tree using `AncestorsWalker`.
+    * For each `dentry`, check if it's in the maps of the domain's layers. If so, unmask layers.
+    * Return permission error if not all layers cleared their masks when reaching root.
+  * `checkLandlockOpen(ctx context.Context, domain *Domain, path vfs.Path, flags uint32) error`:
+    * Map open flags (`O_RDONLY`, `O_WRONLY`, `O_TRUNC`, etc.) to Landlock FS access masks.
+    * Call `checkLandlockPath`.
+
+## 5. Syscall Implementation (`pkg/sentry/syscalls/linux/sys_landlock.go`)
+* `LandlockCreateRuleset`:
+  * Validate parameters (if version requested, return 1).
+  * Read `landlock_ruleset_attr` from user space.
+  * Create `Ruleset` and its `RulesetFileDescription`.
+  * Return FD.
+* `LandlockAddRule`:
+  * Extract `RulesetFileDescription` from FD.
+  * Read `landlock_path_beneath_attr` from user space.
+  * Resolve `parent_fd` to `vfs.Path` / `vfs.Dentry`.
+  * Validate that the rule's allowed accesses are a subset of ruleset's handled accesses.
+  * Insert rule (incrementing ref count of the resolved `Dentry`).
+* `LandlockRestrictSelf`:
+  * Check that `no_new_privs` is set, or task has `CAP_SYS_ADMIN` in user namespace.
+  * Extract `RulesetFileDescription` from FD.
+  * Merge ruleset into the current credentials' domain (creating a new `Domain` that stacks rulesets).
+  * Set task's credentials to the new ones.
+  * Increment the new domain's ref count and register a `TaskDestroyAction` on the task.
+
+## 6. Integration into VFS Layer (`pkg/sentry/vfs/vfs.go` etc.)
+Add hooks:
+* `OpenAt`, `MkdirAt`, `MknodAt`, `SymlinkAt`, `UnlinkAt`, `RmdirAt`, `RenameAt`, `LinkAt`:
+  * Check if Landlock domain is active in task credentials.
+  * If active, call corresponding `checkLandlock` checks.
+  * For `RenameAt`/`LinkAt`, verify they are within same directory (`oldParentVD == newParentVD`) else return `EXDEV` (refer restriction).

+# Test Plan: Landlock ABIs v1
+
+This plan outlines the system call tests to validate the implementation of Landlock ABI v1 in gVisor.
+
+## 1. Test File Location

+## 2. Test Cases
+
+### 2.1. API Version Check
+* **Goal**: Verify that `landlock_create_ruleset` can return the supported ABI version.
+* **Logic**:
+  * Call `syscall(SYS_landlock_create_ruleset, NULL, 0, LANDLOCK_CREATE_RULESET_VERSION)`.
+  * Assert return value is `1` (ABI v1).
+
+### 2.2. Create Ruleset Invalid Parameters
+* **Goal**: Validate error returns for invalid parameters of `landlock_create_ruleset`.
+* **Logic**:
+  * Call with invalid flags: `syscall(SYS_landlock_create_ruleset, attr, size, invalid_flags)` -> expect `EINVAL`.
+  * Call with invalid size (too small): `syscall(SYS_landlock_create_ruleset, attr, size_too_small, 0)` -> expect `EINVAL`.
+  * Call with invalid size (too large): `syscall(SYS_landlock_create_ruleset, attr, size_too_large, 0)` -> expect `EINVAL`.
+  * Call with NULL attr but non-zero size: `syscall(SYS_landlock_create_ruleset, NULL, non_zero_size, 0)` -> expect `EFAULT`.
+  * Call with invalid attr pointer: `syscall(SYS_landlock_create_ruleset, invalid_ptr, size, 0)` -> expect `EFAULT`.
+
+### 2.3. Add Rule Invalid Parameters
+* **Goal**: Validate error returns for invalid parameters of `landlock_add_rule`.
+* **Logic**:
+  * Call with invalid ruleset FD: `syscall(SYS_landlock_add_rule, invalid_fd, LANDLOCK_RULE_PATH_BENEATH, attr, 0)` -> expect `EBADF`.
+  * Call with non-ruleset FD: `syscall(SYS_landlock_add_rule, non_ruleset_fd, LANDLOCK_RULE_PATH_BENEATH, attr, 0)` -> expect `EBADF` or `EINVAL` (actually `EBADF` or `EINVAL` depending on whether it is a valid FD but not a ruleset). On Linux it should return `EINVAL` if it is a valid FD but not a ruleset.
+  * Call with invalid rule type: `syscall(SYS_landlock_add_rule, ruleset_fd, invalid_rule_type, attr, 0)` -> expect `EINVAL`.
+  * Call with NULL attr: `syscall(SYS_landlock_add_rule, ruleset_fd, LANDLOCK_RULE_PATH_BENEATH, NULL, 0)` -> expect `EFAULT`.
+  * Call with invalid parent FD in attr: `syscall(SYS_landlock_add_rule, ruleset_fd, LANDLOCK_RULE_PATH_BENEATH, attr_with_invalid_parent_fd, 0)` -> expect `EBADF`.
+
+### 2.4. Restrict Self Invalid Parameters
+* **Goal**: Validate error returns for invalid parameters of `landlock_restrict_self`.
+* **Logic**:
+  * Call with invalid ruleset FD: `syscall(SYS_landlock_restrict_self, invalid_fd, 0)` -> expect `EBADF`.
+  * Call with invalid flags: `syscall(SYS_landlock_restrict_self, ruleset_fd, invalid_flags)` -> expect `EINVAL`.
+
+### 2.5. Enforcement Requirements (no_new_privs)
+* **Goal**: Verify that `landlock_restrict_self` requires `no_new_privs` or `CAP_SYS_ADMIN`.
+* **Logic**:
+  * Create a ruleset.
+  * Drop `CAP_SYS_ADMIN` (if we have it).
+  * Ensure `no_new_privs` is NOT set.
+  * Call `syscall(SYS_landlock_restrict_self, ruleset_fd, 0)` -> expect `EPERM`.
+  * Set `no_new_privs` using `prctl(PR_SET_NO_NEW_PRIVS, 1, 0, 0, 0)`.
+  * Call `syscall(SYS_landlock_restrict_self, ruleset_fd, 0)` -> expect success.
+
+### 2.6. Basic Path Restrictions (Read/Write)
+* **Goal**: Verify that sandboxed process cannot access files outside allowed paths.
+* **Logic**:
+  * Create two directories: `dir_allowed` and `dir_denied`.
+  * Create a file in each: `dir_allowed/file` and `dir_denied/file`.
+  * Create a ruleset handling `LANDLOCK_ACCESS_FS_READ_FILE` and `LANDLOCK_ACCESS_FS_WRITE_FILE`.
+  * Add a rule allowing `LANDLOCK_ACCESS_FS_READ_FILE` on `dir_allowed`.
+  * Set `no_new_privs` and restrict self.
+  * Try to read `dir_allowed/file` -> expect success.
+  * Try to write `dir_allowed/file` -> expect `EACCES` (since `WRITE_FILE` is handled but not allowed).
+  * Try to read `dir_denied/file` -> expect `EACCES` (since `READ_FILE` is handled and not allowed for this path).
+  * Try to write `dir_denied/file` -> expect `EACCES` (since `WRITE_FILE` is handled and not allowed).
+
+### 2.7. Directory Operations (Mkdir/Rmdir)
+* **Goal**: Verify restrictions on directory creation and removal.
+* **Logic**:
+  * Create a ruleset handling `LANDLOCK_ACCESS_FS_MAKE_DIR` and `LANDLOCK_ACCESS_FS_REMOVE_DIR`.
+  * Restrict self without adding rules.
+  * Try to `mkdir` in a test directory -> expect `EACCES`.
+  * Add rule allowing `MAKE_DIR` and `REMOVE_DIR` on test directory.
+  * Restrict self.
+  * Try to `mkdir` -> expect success.
+  * Try to `rmdir` -> expect success.
+
+### 2.8. Inheritance and Nested Directories
+* **Goal**: Verify that rules apply recursively to descendants.
+* **Logic**:
+  * Create structure: `parent/child/grandchild/file`.
+  * Create ruleset handling `READ_FILE`.
+  * Add rule allowing `READ_FILE` on `parent`.
+  * Restrict self.
+  * Read `parent/child/grandchild/file` -> expect success.
+
+### 2.9. Stacking Rulesets (Limit 16)
+* **Goal**: Verify that we can stack rulesets up to 16 times, and the 17th fails with `E2BIG`.
+* **Logic**:
+  * Loop 16 times:
+    * Create a simple ruleset.
+    * Restrict self.
+    * Assert success.
+  * Create 17th ruleset.
+  * Restrict self -> expect `E2BIG`.
+
+### 2.10. Cross-directory Rename/Link (Implicitly denied in v1)
+* **Goal**: Verify that cross-directory rename/link is denied (returns `EXDEV`).
+* **Logic**:
+  * Create two directories: `dir1` and `dir2`.
+  * Create a file `dir1/file`.
+  * Create a ruleset handling all v1 write/make/remove access rights.
+  * Add rules allowing all access rights on both `dir1` and `dir2`.
+  * Restrict self.
+  * Try to rename `dir1/file` to `dir2/file` -> expect `EXDEV` (since `REFER` is not supported in v1 and thus cannot be allowed).
+  * Try to link `dir1/file` to `dir2/file` -> expect `EXDEV`.

+// Ruleset represents a Landlock ruleset under construction.
+//
+// Matches Linux security/landlock/ruleset.h:struct landlock_ruleset.
+type Ruleset struct {
+	// mu protects the fields below.
+	mu sync.Mutex
+
+	// handledAccessFS is the set of filesystem access rights handled by this ruleset.
+	handledAccessFS uint64
+
+	// rules maps a Dentry to its allowed access mask in this ruleset.
+	// Since rules are added by path, we hold a reference to each dentry in the map.
+	rules map[*vfs.Dentry]uint64
+}
+
+// NewRuleset creates a new Ruleset.
+func NewRuleset(handledAccessFS uint64) *Ruleset {
+	return &Ruleset{
+		handledAccessFS: handledAccessFS,
+		rules:           make(map[*vfs.Dentry]uint64),
+	}
+}
+
+// AddRule adds a path beneath rule to the ruleset.
+func (r *Ruleset) AddRule(d *vfs.Dentry, allowedAccess uint64) error {
+	r.mu.Lock()
+	defer r.mu.Unlock()
+
+	// allowedAccess must be a subset of handledAccessFS.
+	if (allowedAccess | r.handledAccessFS) != r.handledAccessFS {
+		return linuxerr.EINVAL
+	}
+
+	if oldAccess, ok := r.rules[d]; ok {
+		r.rules[d] = oldAccess | allowedAccess
+	} else {
+		d.IncRef()
+		r.rules[d] = allowedAccess
+	}
+	return nil
+}
+
+// HandledAccessFS returns the handled filesystem access rights of this ruleset.
+func (r *Ruleset) HandledAccessFS() uint64 {
+	r.mu.Lock()
+	defer r.mu.Unlock()
+	return r.handledAccessFS
+}
+
+// Freeze returns a new, read-only copy of the Ruleset for use in a Domain.
+// It increments references of all dentries in the copied rules map.
+func (r *Ruleset) Freeze() *Ruleset {
+	r.mu.Lock()
+	defer r.mu.Unlock()
+
+	frozen := &Ruleset{
+		handledAccessFS: r.handledAccessFS,
+		rules:           make(map[*vfs.Dentry]uint64),
+	}
+	for d, access := range r.rules {
+		d.IncRef()
+		frozen.rules[d] = access
+	}
+	return frozen
+}

+// RulesetFileDescription implements vfs.FileDescriptionImpl for the anonymous
+// file descriptor representing a Landlock ruleset.
+type RulesetFileDescription struct {
+	vfs.FileDescriptionDefaultImpl

+	vfs.NoLockFD

+}

+// NewRulesetFD creates a new anonymous file descriptor representing a Ruleset.
+func NewRulesetFD(vfsObj *vfs.VirtualFilesystem, r *Ruleset) (*vfs.FileDescription, error) {
+	vd := vfsObj.NewAnonVirtualDentry("[landlock-ruleset]")
+	defer vd.DecRef(context.Background())

+	}

+// Release implements vfs.FileDescriptionImpl.Release.
+func (fd *RulesetFileDescription) Release(ctx context.Context) {
+	fd.ruleset.mu.Lock()
+	defer fd.ruleset.mu.Unlock()
+
+	// Release references to all dentries.

+		d.DecRef(ctx)
+	}

+	impl, ok := fd.Impl().(*RulesetFileDescription)
+	if !ok {

+//
+// Matches Linux security/landlock/ruleset.h:struct landlock_ruleset (used as a domain).

+func NewDomain(layers []*Ruleset) *Domain {

+		layers: layers,
+	}
+	d.EnableWarning(true)
+	return d

+// Clone implements auth.SecurityObject.Clone.
+func (d *Domain) Clone() auth.SecurityObject {
+	d.IncRef()
+	return d

+// DecRef implements auth.SecurityObject.DecRef (wrapped in refs.AtomicRefCount).
+func (d *Domain) DecRef(ctx context.Context) {
+	d.DecRefWithDestructor(ctx, func(ctx context.Context) {

+		for _, layer := range d.layers {
+			for dentry := range layer.rules {
+				dentry.DecRef(ctx)
+			}
+		}
+	})

+var sizeofLandlockRulesetAttr = (*linux.LandlockRulesetAttr)(nil).SizeBytes()

+// LandlockCreateRuleset implements linux syscall landlock_create_ruleset(2).
+func LandlockCreateRuleset(t *kernel.Task, sysno uintptr, args arch.SyscallArguments) (uintptr, *kernel.SyscallControl, error) {
+	addr := args[0].Pointer()
+	size := args[1].SizeT()
+	flags := args[2].Uint()
+
+	if flags&linux.LANDLOCK_CREATE_RULESET_VERSION != 0 {
+		return 1, nil, nil // We support ABI v1
+	}
+
+	if flags != 0 {
+		return 0, nil, linuxerr.EINVAL
+	}
+
+	minSize := uint(sizeofLandlockRulesetAttr)
+	if size < minSize {
+		return 0, nil, linuxerr.EINVAL
+	}
+
+	var attr linux.LandlockRulesetAttr
+	if _, err := attr.CopyIn(t, addr); err != nil {
+		return 0, nil, err
+	}
+
+	// We only support FS access rights in ABI v1.
+	if attr.HandledAccessNet != 0 || attr.Scoped != 0 {
+		return 0, nil, linuxerr.EINVAL
+	}
+
+	// Only allow access rights defined in ABI v1.
+	if attr.HandledAccessFS&^linux.LANDLOCK_MASK_ACCESS_FS != 0 {
+		return 0, nil, linuxerr.EINVAL
+	}
+
+	ruleset := landlock.NewRuleset(attr.HandledAccessFS)
+	fd, err := landlock.NewRulesetFD(t.Kernel().VFS(), ruleset)
+	if err != nil {
+		return 0, nil, err
+	}
+	defer fd.DecRef(t)
+
+	newFD, err := t.NewFDFrom(0, fd, kernel.FDFlags{
+		CloseOnExec: true, // Landlock FDs are close-on-exec by default
+	})
+	if err != nil {
+		return 0, nil, err
+	}
+
+	return uintptr(newFD), nil, nil
+}

+// LandlockAddRule implements linux syscall landlock_add_rule(2).
+func LandlockAddRule(t *kernel.Task, sysno uintptr, args arch.SyscallArguments) (uintptr, *kernel.SyscallControl, error) {
+	rulesetFD := args[0].Int()
+	ruleType := args[1].Int()
+	ruleAttrAddr := args[2].Pointer()
+	flags := args[3].Uint()
+
+	if flags != 0 {
+		return 0, nil, linuxerr.EINVAL
+	}
+
+	if ruleType != linux.LANDLOCK_RULE_PATH_BENEATH {
+		return 0, nil, linuxerr.EINVAL
+	}
+
+	// Retrieve Ruleset from rulesetFD.
+	rulesetFile := t.GetFile(rulesetFD)
+	if rulesetFile == nil {
+		return 0, nil, linuxerr.EBADF
+	}
+	defer rulesetFile.DecRef(t)
+
+	ruleset, err := landlock.GetRulesetFromFD(rulesetFile)
+	if err != nil {
+		return 0, nil, err
+	}
+
+	var attr linux.LandlockPathBeneathAttr
+	if _, err := attr.CopyIn(t, ruleAttrAddr); err != nil {
+		return 0, nil, err
+	}
+
+	// Get target dentry from ParentFD.
+	parentFile := t.GetFile(attr.ParentFD)
+	if parentFile == nil {
+		return 0, nil, linuxerr.EBADF
+	}
+	defer parentFile.DecRef(t)
+
+	parentVD := parentFile.VirtualDentry()
+
+	// Add rule to ruleset.
+	if err := ruleset.AddRule(parentVD.Dentry(), attr.AllowedAccess); err != nil {
+		return 0, nil, err
+	}
+
+	return 0, nil, nil
+}

+// LandlockRestrictSelf implements linux syscall landlock_restrict_self(2).
+func LandlockRestrictSelf(t *kernel.Task, sysno uintptr, args arch.SyscallArguments) (uintptr, *kernel.SyscallControl, error) {
+	rulesetFD := args[0].Int()
+	flags := args[1].Uint()
+
+	if flags != 0 {
+		return 0, nil, linuxerr.EINVAL
+	}
+
+	// Check no_new_privs or CAP_SYS_ADMIN in user namespace.
+	if !t.NoNewPrivs() && !t.Credentials().HasCapabilityIn(linux.CAP_SYS_ADMIN, t.UserNamespace()) {
+		return 0, nil, linuxerr.EPERM
+	}
+
+	// Retrieve Ruleset from rulesetFD.
+	rulesetFile := t.GetFile(rulesetFD)
+	if rulesetFile == nil {
+		return 0, nil, linuxerr.EBADF
+	}
+	defer rulesetFile.DecRef(t)
+
+	ruleset, err := landlock.GetRulesetFromFD(rulesetFile)
+	if err != nil {
+		return 0, nil, err
+	}
+
+	// Freeze the ruleset.
+	frozenRuleset := ruleset.Freeze()
+
+	// Fork credentials.
+	creds := t.Credentials().Fork()
+
+	var newDomain *landlock.Domain
+	if creds.Security == nil {
+		newDomain = landlock.NewDomain([]*landlock.Ruleset{frozenRuleset})
+	} else {
+		oldDomain, ok := creds.Security.(*landlock.Domain)
+		if !ok {
+			return 0, nil, linuxerr.EPERM
+		}
+		newDomain = oldDomain.Merge(frozenRuleset)
+	}
+
+	creds.Security = newDomain
+	t.UpdateCredentials(creds)
+	return 0, nil, nil
+}

+// WalkAncestors walks up the parent chain of d and calls cb on each dentry.
+// It acquires ancestryMu read lock for the duration of the walk.
+func WalkAncestors(fs *Filesystem, d *Dentry, cb func(*Dentry) bool) {
+	fs.ancestryMu.RLock()
+	defer fs.ancestryMu.RUnlock()
+	for curr := d; curr != nil; curr = curr.parent.Load() {
+		if !cb(curr) {
+			break
+		}
+	}

+// LandlockDomain represents the interface that a Landlock domain must implement
+// to allow VFS to perform Landlock path verification checks.
+type LandlockDomain interface {
+	// NumLayers returns the number of layers in the domain.
+	NumLayers() int
+
+	// HandledAccessFS returns the handled filesystem access rights of the given layer.
+	HandledAccessFS(layer int) uint64
+
+	// GetRule returns the allowed access mask for a dentry in the given layer,
+	// and true if a rule exists.
+	GetRule(layer int, d *Dentry) (uint64, bool)
+}

+// CheckLandlockOpen checks Landlock permissions for open operations.
+func (vfs *VirtualFilesystem) CheckLandlockOpen(ctx context.Context, creds *auth.Credentials, vd VirtualDentry, flags uint32) error {
+	if creds.Security == nil {
+		return nil
+	}
+	domain, ok := creds.Security.(LandlockDomain)
+	if !ok {
+		return nil
+	}
+
+	// Map open flags to Landlock FS access rights.
+	var accessRequest uint64
+	accMode := flags & linux.O_ACCMODE
+	if accMode == linux.O_WRONLY || accMode == linux.O_RDWR {
+		accessRequest |= linux.LANDLOCK_ACCESS_FS_WRITE_FILE
+	}
+	if accMode == linux.O_RDONLY || accMode == linux.O_RDWR {
+		accessRequest |= linux.LANDLOCK_ACCESS_FS_READ_FILE
+	}
+	if flags&linux.O_DIRECTORY != 0 {
+		accessRequest |= linux.LANDLOCK_ACCESS_FS_READ_DIR
+	}
+
+	return vfs.checkLandlockPath(ctx, domain, vd, accessRequest)
+}
+
+// CheckLandlockPath checks Landlock permissions for a path.
+func (vfs *VirtualFilesystem) CheckLandlockPath(ctx context.Context, creds *auth.Credentials, vd VirtualDentry, accessRequest uint64) error {
+	if creds.Security == nil {
+		return nil
+	}
+	domain, ok := creds.Security.(LandlockDomain)
+	if !ok {
+		return nil
+	}
+	return vfs.checkLandlockPath(ctx, domain, vd, accessRequest)
+}

+func (vfs *VirtualFilesystem) checkLandlockPath(ctx context.Context, domain LandlockDomain, vd VirtualDentry, accessRequest uint64) error {
+	if accessRequest == 0 {
+		return nil
+	}
+
+	// Skip checks for mounts that are not user-visible (e.g. pipefs, sockfs).
+	if vd.mount.neverConnected() {
+		return nil
+	}
+
+	numLayers := domain.NumLayers()
+	if numLayers == 0 {
+		return nil
+	}
+
+	// Initialize layer masks.
+	// layerMasks[bit] is a bitmask of layers that restrict the access right at index 'bit'.
+	var layerMasks [16]uint16
+	var handledAccesses uint64
+
+	for layer := 0; layer < numLayers; layer++ {
+		layerBit := uint16(1 << layer)
+		handledFS := domain.HandledAccessFS(layer)
+
+		for bit := 0; bit < 16; bit++ {
+			accessBit := uint64(1 << bit)
+			if (accessRequest & accessBit) != 0 {
+				if (handledFS & accessBit) != 0 {
+					layerMasks[bit] |= layerBit
+					handledAccesses |= accessBit
+				}
+			}
+		}
+	}
+
+	// If none of the layers handle any of the requested accesses, it's allowed.
+	if handledAccesses == 0 {
+		return nil
+	}
+
+	// Resolve the task's VFS root to stop the walk when we reach it.
+	root := RootFromContext(ctx)
+	defer root.DecRef(ctx)
+
+	// Walk up the ancestry tree.
+	curr := vd
+	curr.IncRef()
+	defer curr.DecRef(ctx)
+
+	for {
+		// Check if the filesystem implements AncestorsWalker.
+		walker, ok := curr.dentry.impl.Filesystem().impl.(AncestorsWalker)
+		if !ok {
+			// If we can't walk ancestors, we must stop and fail.
+			return linuxerr.EACCES
+		}
+
+		var walkErr error
+		// Walk up within the current filesystem.
+		walkErr = walker.WalkAncestors(ctx, curr.dentry, func(d *Dentry) bool {
+			// Check if we hit the root of the task.
+			if curr.mount == root.Mount() && d == root.Dentry() {
+				// We hit the chroot boundary. Stop walking.
+				return false
+			}
+
+			// For each layer, check if there is a rule for this dentry.
+			for layer := 0; layer < numLayers; layer++ {
+				layerBit := uint16(1 << layer)
+				if allowedAccess, ok := domain.GetRule(layer, d); ok {
+					// Clear the layer's bit from all access rights that are allowed by this rule.
+					for bit := 0; bit < 16; bit++ {
+						accessBit := uint64(1 << bit)
+						if (allowedAccess & accessBit) != 0 {
+							layerMasks[bit] &^= layerBit
+						}
+					}
+				}
+			}
+
+			// Check if all layers have allowed all requested accesses.
+			allAllowed := true
+			for bit := 0; bit < 16; bit++ {
+				accessBit := uint64(1 << bit)
+				if (handledAccesses & accessBit) != 0 {
+					if layerMasks[bit] != 0 {
+						allAllowed = false
+						break
+					}
+				}
+			}
+			if allAllowed {
+				return false // stop walking
+			}
+
+			return true // continue walking up
+		})
+
+		if walkErr != nil {
+			return walkErr
+		}
+
+		// Check if we are done (all allowed).
+		allAllowed := true
+		for bit := 0; bit < 16; bit++ {
+			accessBit := uint64(1 << bit)
+			if (handledAccesses & accessBit) != 0 {
+				if layerMasks[bit] != 0 {
+					allAllowed = false
+					break
+				}
+			}
+		}
+		if allAllowed {
+			return nil
+		}
+
+		// If we reached the task chroot root, stop.
+		if curr.mount == root.Mount() && curr.dentry == root.Dentry() {
+			return linuxerr.EACCES
+		}
+
+		// If we reached the mount root, cross the mount boundary.
+		if curr.dentry == curr.mount.Root() {
+			parentVD := vfs.getMountpointAt(ctx, curr.mount, root)
+			if parentVD.Ok() {
+				curr.DecRef(ctx)
+				curr = parentVD
+				// parentVD is returned with a reference taken, so we just continue.
+				continue
+			} else {
+				// Reached the absolute root.
+				return linuxerr.EACCES
+			}
+		}
+
+		// If WalkAncestors finished without reaching the mount root or chroot, but we still aren't allowed:
+		if curr.dentry != curr.mount.Root() {
+			return linuxerr.EACCES
+		}
+	}
+}

+TEST_F(LandlockTest, CrossDirectoryRenameLinkDenied) {
+  std::string tmp_dir = NewTempAbsPath();
+  ASSERT_THAT(mkdir(tmp_dir.c_str(), 0777), SyscallSucceeds());
+
+  std::string dir1 = JoinPath(tmp_dir, "dir1");
+  std::string dir2 = JoinPath(tmp_dir, "dir2");
+  ASSERT_THAT(mkdir(dir1.c_str(), 0777), SyscallSucceeds());
+  ASSERT_THAT(mkdir(dir2.c_str(), 0777), SyscallSucceeds());
+
+  std::string file1 = JoinPath(dir1, "file1");
+  int fd;
+  ASSERT_THAT(fd = open(file1.c_str(), O_RDWR | O_CREAT, 0666), SyscallSucceeds());
+  close(fd);
+
+  RunInFork([&]() {
+    ASSERT_THAT(prctl(PR_SET_NO_NEW_PRIVS, 1, 0, 0, 0), SyscallSucceeds());
+
+    uint64_t access_mask =
+        LANDLOCK_ACCESS_FS_WRITE_FILE | LANDLOCK_ACCESS_FS_REMOVE_FILE |
+        LANDLOCK_ACCESS_FS_MAKE_REG;
+
+    struct landlock_ruleset_attr attr = {
+      .handled_access_fs = access_mask,
+    };
+    int ruleset_fd = syscall(__NR_landlock_create_ruleset, &attr, sizeof(attr), 0);
+    ASSERT_GE(ruleset_fd, 0);
+    auto cleanup_ruleset = FileDescriptor(ruleset_fd);
+
+    int dir1_fd = open(dir1.c_str(), O_PATH | O_DIRECTORY);
+    ASSERT_GE(dir1_fd, 0);
+    auto cleanup_dir1 = FileDescriptor(dir1_fd);
+
+    int dir2_fd = open(dir2.c_str(), O_PATH | O_DIRECTORY);
+    ASSERT_GE(dir2_fd, 0);
+    auto cleanup_dir2 = FileDescriptor(dir2_fd);
+
+    struct landlock_path_beneath_attr path_attr1 = {
+      .allowed_access = access_mask,
+      .parent_fd = dir1_fd,
+    };
+    ASSERT_THAT(syscall(__NR_landlock_add_rule, ruleset_fd,
+                        LANDLOCK_RULE_PATH_BENEATH, &path_attr1, 0),
+                SyscallSucceeds());
+
+    struct landlock_path_beneath_attr path_attr2 = {
+      .allowed_access = access_mask,
+      .parent_fd = dir2_fd,
+    };
+    ASSERT_THAT(syscall(__NR_landlock_add_rule, ruleset_fd,
+                        LANDLOCK_RULE_PATH_BENEATH, &path_attr2, 0),
+                SyscallSucceeds());
+
+    ASSERT_THAT(syscall(__NR_landlock_restrict_self, ruleset_fd, 0),
+                SyscallSucceeds());
+
+    std::string file1_renamed = JoinPath(dir1, "file1_renamed");
+    EXPECT_THAT(rename(file1.c_str(), file1_renamed.c_str()), SyscallSucceeds());
+    EXPECT_THAT(rename(file1_renamed.c_str(), file1.c_str()), SyscallSucceeds());
+
+    std::string file1_link = JoinPath(dir1, "file1_link");
+    EXPECT_THAT(link(file1.c_str(), file1_link.c_str()), SyscallSucceeds());
+    EXPECT_THAT(unlink(file1_link.c_str()), SyscallSucceeds());
+
+    std::string file2 = JoinPath(dir2, "file2");
+    EXPECT_THAT(rename(file1.c_str(), file2.c_str()), SyscallFailsWithErrno(EXDEV));
+
+    EXPECT_THAT(link(file1.c_str(), file2.c_str()), SyscallFailsWithErrno(EXDEV));
+  });
+
+  unlink(file1.c_str());
+  rmdir(dir1.c_str());
+  rmdir(dir2.c_str());
+  rmdir(tmp_dir.c_str());
+}
